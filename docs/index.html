Features

Engineered for developer bliss

Precision tools, clean outputs, and native protocol integration.

Retro Mascot & Purple Palette

8-bit purple mascot coupled with high-contrast accents and dark zinc terminal formatting.

Live Diamond Thinking Loader

Pulsing geometric diamond animation with live seconds timer during model thinking and tool execution.

Tree-Node Tool Executions

Clean ● Tool() ⎿ Output formatting keeps tool progress clear without cluttering your workspace.

Plan Mode & Safety Approvals

Dry-run safe architecture planning with /plan, or toggle session-wide auto-approvals with /auto.

Model Context Protocol (MCP)

Connect external databases, APIs, and specialized CLI tools directly through standard mcp_config.json.

Auto Context Compaction

Intelligent context summarization kicks in automatically when token limits approach, preserving tokens and cost.

Productivity

Built-in Slash Commands

Fine-grained control over models, tools, and token contexts.

Command Category Description & Functionality
/plan Safety Mode Blocks all write tools for risk-free architectural and planning passes.
/auto Execution Executes write tools and shell commands without requiring interactive approval.
/status Inspection Displays active LLM model, git branch, message token volume, and MCP servers.
/model <id> Routing Dynamically switches the active LLM (Claude 3.5 Sonnet, Gemini 2.5, GPT-4o, etc.).
/compact Optimization Compresses historical tool outputs to reclaim valuable model context space.
/mcp Integration Lists connected Model Context Protocol servers and their exposed tools.
/clear Session Clears current chat history and refreshes repository context from disk.
/help Guide Prints full command palette and active tool descriptions in terminal.
Get Started

Up and running in 30 seconds

Launch directly from your command line without cloning repositories.

1

Run in any folder

Open your project directory in your terminal and execute:

npx sudocode-ai
2

Connect your API key

On first launch, press o to open openrouter.ai/keys. Paste your key and it's saved in ~/.sudocode/config.json.

3

Prompt & Iterate

Ask SudoCode to fix bugs, refactor code, run test suites, or generate new files in real time.
